## Features

This project aims at centralising the Garmin and Strava data for running to get better insights for my training.
It includes data visualisation of key metrics (VO2max, Weekly mileage, resting heart rate...) and a chatbot powered by Mistral that has access to my data to give me insights on my training. 

## Why I did this project

This first project's aim -appart from the improved training - is to introduce me to building apps, getting more familiar with github
